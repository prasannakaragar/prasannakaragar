# Embedded Font Licenses

This directory contains the font assets and corresponding SIL Open Font Licenses (OFL-1.1) used in the animated SVG assets for Prasanna Karagar's GitHub profile.

## 1. Space Grotesk (Bold 700)
- **Author/Designer:** Florian Karsten
- **Upstream Repository:** https://github.com/floriankarsten/space-grotesk
- **License:** SIL Open Font License, Version 1.1 (see `SPACE_GROTESK_OFL.txt`)
- **Usage:** Used as the primary bold display font for headers, hero name reveal, and typography cards.

## 2. JetBrains Mono (SemiBold 600)
- **Author/Designer:** JetBrains
- **Upstream Repository:** https://github.com/JetBrains/JetBrainsMono
- **License:** SIL Open Font License, Version 1.1 (see `JETBRAINS_MONO_OFL.txt`)
- **Usage:** Used as the monospace font for terminal headers, code badges, metadata, and status indicators.
